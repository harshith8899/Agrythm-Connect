# TRL Plan — Agrythm Connect

Level names (management scale): 0 Idea · 1 Basic research · 2 Technology formulation · 3 Needs validation · 4 Small scale prototype · 5 Large scale prototype · 6 Prototype system · 7 Demonstration system · 8 First of a kind commercial system · 9 Full commercial application. The animated picture in `README.md` is generated by `scripts/make_trl_ladder.py`.

Rule: do not start a TRL's work until the previous TRL's exit gate has passing evidence. Update the **Status** and **Evidence** columns at each weekly gate review.

| TRL | Scope | Exit gate (PRD acceptance gates) | Status | Evidence |
|---|---|---|---|---|
| **3** Lab proof | Text-only loop on mock data: event → context → conversation → structured outcome. Typed Hindi/English. | Gates 1, 2, 4 pass; all 4 outcomes reachable; first safety checks pass | In progress | `pytest` (tests/test_gate1…4) |
| **4** Lab integration | STT/TTS adapters, browser voice loop, LLM adapter (free tier) behind the policy gate, safety set grown to 50–100 utterances | Gate 3 (safety): zero unapproved molecule/dose/compatibility/PHI output on the full set | Not started | |
| **5** Relevant environment | Retry scheduler, call windows, fallback (WhatsApp/SMS), failure states S05–S09, Streamlit operator screens C01/C02/C04/C05, replay of real farmer audio | Gate 5 (recovery); measured STT accuracy on real accents | Not started | |
